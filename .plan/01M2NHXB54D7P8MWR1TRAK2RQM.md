# 创建鹈鹕 SVG 展示页

## 目标
在工作区根目录创建 `pelican.html`，居中展示一只**简洁扁平图标风**的鹈鹕 SVG。

## 改动文件
- 新建：`/Users/token/Desktop/code/NextCoWork/pelican.html`（唯一改动，独立静态页，不接入项目的 i18n / React 体系）

## 实现内容

### HTML 结构
- 标准 `<!DOCTYPE html>`，`lang="zh-CN"`，UTF-8，viewport meta
- `<title>` 设为「鹈鹕」
- body 内联一段 CSS：
  - 页面 100vh 居中对齐（`display:flex; align-items:center; justify-content:center`）
  - 浅灰背景（如 `#f5f5f5`）
  - SVG 宽度约 320px，自适应高度
- body 内联一个 `<svg viewBox="0 0 200 200">`，无外部资源依赖

### SVG 鹈鹕设计（扁平图标风）
侧面朝右的鹈鹕，用基础图形拼合，约 5 个色块：

1. **身体**：白色/浅灰大椭圆，位于画面左下
2. **翅膀**：比身体稍深的灰色椭圆，叠加在身体上方
3. **头部**：白色圆形，位于右上，与身体相连（可用短矩形/路径连接颈部）
4. **喙**：长橙色三角形/梯形，从头部向右伸出
5. **喉袋**：喙下方一条浅橙色弧形 path（鹈鹕标志性特征，保留但简化）
6. **眼睛**：头部上的深色小圆点
7. **脚**：身体底部两小段橙色横线

配色参考（扁平、少色）：
- 身体/头：`#ffffff`（带浅灰 `#e0e0e0` 描边或阴影区分层次）
- 翅膀：`#cfd8dc`
- 喙/脚：`#ff9800`，喉袋 `#ffb74d`
- 眼睛：`#263238`
