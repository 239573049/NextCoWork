# 计划：鹈鹕骑单车 SVG 动画 HTML

## 目标
创建一个独立的单文件 HTML 页面，内嵌 SVG 绘制的"鹈鹕骑单车"场景，带循环动画。双击即可在浏览器打开，无任何外部依赖。

## 产出文件
- `/Users/token/Desktop/code/NextCoWork/pelican-bicycle.html`（新建，唯一改动）

## 技术方案
- 纯 HTML + 内联 SVG + 内联 CSS 动画（`<style>` 标签），不使用 JS，不使用外部资源。
- 页面结构：深色渐变背景的全屏容器，居中放置一个 `viewBox="0 0 800 600"` 的 SVG。
- `<title>` 与少量页面文字使用中文（如"鹈鹕骑单车"）。

## SVG 场景组成
1. **背景**：天空渐变、太阳、几朵云（云做水平飘移动画）、远山、地面/道路横线。
2. **自行车**（一个 `<g>`，整体从画面左侧匀速移动到右侧并循环）：
   - 两个车轮：圆 + 轮辐，绕各自车轴 `transform: rotate()` 无限旋转（CSS `@keyframes`，`transform-origin` 设在轮心）。
   - 车架：连接前后轮的三角形线条。
   - 脚踏曲柄：绕中轴旋转，与车轮联动方向一致。
   - 车座、车把。
3. **鹈鹕**（与车同组）：
   - 身体：白色椭圆略前倾；翅膀：附着于身体的羽毛形状，做小幅上下扇动动画（模拟踩踏节奏）。
   - 头颈：S 形长颈；头部 + 标志性的大喙（上喙 + 下垂的喉囊，橙色）。
   - 腿：两条腿连接脚踏，随曲柄旋转做上下踩踏动画（错开 180° 相位）。
   - 身体整体做轻微上下起伏（模拟骑行颠簸），相位与踏频协调。
4. **细节**：车轮旁几条速度线、地面小石子或花草点缀。

## 动画清单（CSS keyframes）
| 动画 | 元素 | 说明 |
|---|---|---|
| wheel-spin | 两轮 | 360° 旋转，约 1s 线性循环 |
| pedal-spin | 曲柄/脚踏 | 同方向旋转，约 1.2s |
| leg-kick-l/r | 两腿 | 上下位移，相位相反 |
| body-bob | 鹈鹕躯干 | 轻微上下起伏 |
| wing-flap | 翅膀 | 小角度旋转扇动 |
| ride-across | 整车组 | translateX 从 -300 到 1100，约 6s 线性循环 |
| cloud-drift | 云朵 | 慢速水平漂移，不同时长错开 |
