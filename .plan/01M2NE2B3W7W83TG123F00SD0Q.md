# 计划:鹈鹕骑单车 SVG HTML 文件

## 目标
创建一个独立 HTML 文件,内嵌细致插画风格的静态 SVG,画面为一只鹈鹕骑单车。

## 新建文件
- `/Users/token/Desktop/code/NextCoWork/pelican-bike.html`(唯一需要创建的文件)

## 文件结构
- 标准 HTML5 骨架(`<!DOCTYPE html>`、`<meta charset="utf-8">`、viewport meta、`<title>`)。
- 内联 `<style>`:页面居中布局、柔和背景色、SVG 最大宽度约束;无需任何外部依赖或脚本。
- 单个 `<svg viewBox="0 0 800 600">`,语义化分组(`<g id="...">`),便于阅读。

## SVG 画面构成(细致插画风格,全部静态)
1. **背景**:天空渐变(`<linearGradient>`)、太阳、几朵云、远处的山丘、地面/路面带透视线条,少量草地装饰。
2. **自行车(后轮驱动透视,侧视图)**:
   - 两个车轮:轮胎(深色圆环)、轮圈(浅色)、多根辐条(细线)、轮毂。
   - 车架:菱形车架(下管、立管、上管、前叉、后叉),用带圆角的折线/路径绘制。
   - 车把(带把套)、车座、链条与牙盘、脚踏曲柄。
3. **鹈鹕(坐姿骑行)**:
   - 白色/浅灰身体(带羽毛层次感的路径与浅色阴影)。
   - 标志性长喙+喉囊(橙黄色,上下喙分层,喉囊用柔和的袋状曲线)。
   - 圆眼+瞳孔、头顶小羽冠。
   - 翅膀向后微张(骑行姿态),羽毛分层路径。
   - 双腿弯曲踩踏板,脚蹼置于脚踏上。
   - 尾巴短羽。
4. **细节装饰**:车轮后速度线(可选,静态弧线)、路面阴影(半透明椭圆)、高光笔触。

## 颜色与技法
- 使用 `<defs>` 中的 `linearGradient` / `radialGradient` 做天空、身体、喙的柔和过渡。
- 调色:鹈鹕身体 `#f5f2ea`~`#ffffff`,喙 `#f0a03c`~`#e07b39`,车架青绿或珊瑚红,天空 `#aee2f5`。
- 线条统一 `stroke-linecap="round"`,整体圆润卡通但细节丰富。

## 边界情况
- 纯静态,无 JavaScript、无 SMIL/CSS 动画。
- 文件自包含,无网络资源,任何现代浏览器直接打开即可。
- SVG 使用 `viewBox` + `width:100%; height:auto`,缩放不失真。
- 这是根目录下的独立展示文件,不接入应用的 i18n 层(非应用 UI 代码,无用户可见的应用内文案)。

## 验证
- 在浏览器中打开该文件,确认:鹈鹕与单车比例协调、无重叠错位、渐变正常渲染。
- 用文本检查确认文件无外部引用(`grep -i "http\|src=\|href=" pelican-bike.html` 仅允许 `<a>`/命名空间声明之外为空)。
