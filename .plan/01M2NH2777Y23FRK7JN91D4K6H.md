# 鹈鹕骑单车 SVG HTML 文件

## 目标

创建一个独立的、可直接在浏览器打开的 HTML 文件，内嵌 SVG 绘制「鹈鹕骑单车」，卡通扁平风格，带动画。**不改动 NextCoWork 项目的任何现有代码**（不属于应用 UI，AGENTS.md 的 i18n 规则不适用；文件内文案极少或没有）。

## 产出文件

- `/Users/token/Desktop/code/NextCoWork/pelican-bike.html`（新增，唯一文件；不提交 git）

## 技术方案

- 单文件 HTML：`<style>` 内联 CSS + 内联 `<svg>`，零依赖、零网络请求。
- SVG viewBox 约 `0 0 800 600`，居中显示，页面背景用浅色渐变。
- 全部动画用纯 CSS `@keyframes`（配合 `transform-box: fill-box; transform-origin: center`），不用 JS、不用 SMIL，兼容性最好。
- 尊重 `prefers-reduced-motion`：媒体查询内关闭动画。

## SVG 场景构成（卡通扁平）

1. **背景**：圆形太阳、几朵简笔云（缓慢横向漂移）、远处小山、地面横线。
2. **单车**（分组 `#bike`）：
   - 两个车轮：圆环 + 车条（`<line>` 组），动画 `spin` 绕轮心匀速旋转。
   - 车架：三角形框架（描边折线）、车座、车把。
   - 牙盘 + 踏板：旋转动画，与车轮同方向。
3. **鹈鹕**（分组 `#pelican`）：
   - 白色身体（椭圆）、S 形脖颈、大头 + 标志性长喙（橙色，含下喙囊）。
   - 一只圆眼、翅膀（随蹬踏轻微上下摆动，`rotate` 小角度往复）。
   - 两条腿连到踏板，用简单的腿部组做蹬踏旋转动画（与牙盘同角速度）。
   - 身体整体加轻微上下颠簸（`translateY` 往复）模拟骑行。
4. **速度感**：地面几条短虚线向后移动（`translateX` 循环），云朵漂移。
5. **标题**：SVG 内 `<text>` 显示 "Pelican on a Bike"（装饰性，非应用 UI 文案）。

## 动画清单

| 元素 | 动画 | 时长 |
|---|---|---|
| 车轮 | 旋转 360° | 1.2s 线性无限 |
| 牙盘/踏板/腿 | 旋转 360° | 1.2s 线性无限（与车轮同步） |
| 翅膀 | 上下摆动 ±8° | 0.6s 交替无限 |
| 身体 | 上下颠簸 3px | 0.6s 交替无限 |
| 云 | 横向漂移 | 20–35s 线性无限（两朵错开） |
| 地面虚线 | 向后平移 | 0.8s 线性无限 |
