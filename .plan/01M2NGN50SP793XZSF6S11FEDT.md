# 计划:鹈鹕骑单车 SVG HTML 文件

## 目标
创建一个独立的 HTML 文件,内嵌 SVG 绘制一只鹈鹕骑自行车的插画,风格为**简洁线条**(少量颜色的线稿),并带有**动画效果**(车轮转动、踏板踩踏等)。

## 产出文件
- **唯一新建文件**:`/Users/token/Desktop/code/NextCoWork/pelican-bike.html`
- 不修改仓库中任何其他文件。该文件为独立演示页,不属于应用前端,因此不涉及 `src/renderer/src/i18n/` 的 i18n 规则(页面内不放置需要翻译的 UI 文案,仅含极少量装饰性英文标题或完全无文字)。

## 技术方案
- 单文件 HTML,内联 `<style>` + 内联 `<svg>`,无外部依赖,双击即可在浏览器打开。
- SVG viewBox 约为 `0 0 800 600`,居中显示,页面背景浅色。
- 线条风格:`stroke` 为主(深灰/近黑色 `#333`),`fill: none` 或少量点缀色(如鹈鹕喙用橙黄 `#f5a623`、车筐/车座用棕色),线宽 4–6,`stroke-linecap="round"` 使线条圆润。

## SVG 构图(从左到右)
1. **自行车**:
   - 两个车轮:`<circle>` + 轮毂 + 4–6 根辐条(`<line>`),辐条编组 `<g>` 以便整体旋转。
   - 车架:用 `<line>`/`<path>` 画出三角车架、前叉、车把、车座、链条(可选虚线)。
   - 牙盘 + 左右脚踏:编组 `<g>` 绕牙盘中心旋转。
2. **鹈鹕**(骑在车上):
   - 身体:圆润的 `<ellipse>`/`<path>` 轮廓(白色填充 + 描边)。
   - 长喙 + 喉囊:向前伸出的标志性大喙,橙黄色点缀。
   - 头 + 眼睛(圆点)+ 头顶羽毛。
   - 翅膀:简化为一两片弧线。
   - 两条腿向下踩到脚踏上,腿与脚踏编组联动(或简化为腿随踏板做小幅上下运动)。
3. **装饰**(可选、保持简洁):地面一条地平线、几朵简笔云或速度线。

## 动画方案(CSS 动画为主)
- `@keyframes spin`:两个车轮的辐条组 `transform: rotate(360deg)` 无限循环,`transform-origin` 设为各轮中心,周期约 1s,线性。
- `@keyframes pedal`:牙盘+脚踏组同步旋转(同周期)。
- `@keyframes bob`:鹈鹕身体组轻微上下起伏(`translateY` ±4px,周期 0.5s),模拟骑行动态。
- `@keyframes legs`:双腿随踏板交替上下(可用两个反相的小幅位移动画)。
- `@keyframes move-bg`:地面/云朵向左缓慢平移,营造前进感(可选,简单实现:地面虚线 `stroke-dashoffset` 动画)。
- 尊重无障碍偏好:`@media (prefers-reduced-motion: reduce)` 下关闭动画。

## 实现注意点
- SVG 元素上 CSS `transform` 需配合 `transform-box: fill-box` 与 `transform-origin: center`,确保绕自身中心旋转。
- 所有坐标一次性算好:轮心 y 坐标一致、脚踏半径与腿长匹配,避免穿帮。
- 页面 `<title>` 用英文或不含文案,避免引入需翻译的 UI 字符串。
